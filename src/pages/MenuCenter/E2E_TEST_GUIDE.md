# 套餐增强功能端到端测试指南

## 测试场景

### 1. 创建不使用新功能的套餐（后向兼容性）

**步骤：**
1. 打开菜单中心
2. 点击"创建套餐"
3. 填写基本信息：
   - 名称：测试套餐1
   - 描述：基础套餐
   - 分类：任选一个
4. 不勾选"启用商品分组"
5. 不上传图片
6. 不启用时段限制
7. 添加至少一个商品
8. 设置价格和折扣
9. 点击"创建"

**预期结果：**
- ✓ 套餐创建成功
- ✓ 套餐列表中可见
- ✓ 无图片显示（imageUrl为空）
- ✓ 无分组配置（itemGroups为空）
- ✓ 无时段限制（availabilityRules为空）

---

### 2. 创建使用商品分组的套餐

**步骤：**
1. 点击"创建套餐"
2. 填写基本信息
3. **勾选"启用商品分组"** - 应显示分组配置界面
4. 点击"添加商品分组"
5. 配置第一个分组：
   - 名称：主食选择
   - 类型：单选（N选1）
   - 自动设置为最小1、最大1
6. 在商品列表中添加商品
7. 将商品分配到分组（通过拖拽或下方的分组选择）
8. 添加第二个分组：
   - 名称：小食任选2款
   - 类型：多选（任选N）
   - 设置选择数：2 ~ 3 项
9. 分配商品到第二个分组
10. 点击"创建"

**预期结果：**
- ✓ 分组配置界面正常显示
- ✓ 可以添加/编辑/删除分组
- ✓ 单选和多选模式正确配置
- ✓ 商品正确分配到分组
- ✓ 后端正确保存分组配置（itemGroups）
- ✓ 后端正确保存商品与分组的关联（groupId）

---

### 3. 创建使用时段限制的套餐

**步骤：**
1. 点击"创建套餐"
2. 填写基本信息和商品
3. 在"时段限制（可选）"卡片中：
   - **勾选"启用时段限制"**
4. 勾选"限制可用时间段"：
   - 开始时间：09:00
   - 结束时间：21:30
5. 勾选"限制可用星期"：
   - 选择：周一、周二、周三、周四、周五（工作日）
   - 或点击"工作日"快捷标签
6. 观察预览区域显示：`09:00 - 21:30 | 一、二、三、四、五`
7. 点击"创建"

**预期结果：**
- ✓ 时段限制配置界面正常显示
- ✓ TimePicker正常工作
- ✓ 可以选择星期
- ✓ 快捷标签（工作日/周末/全选）正常工作
- ✓ 预览正确显示所选的时间和星期
- ✓ 后端正确保存时段限制配置（availabilityRules）

**可选测试步骤：**
- 只设置时间段，不设置星期
- 只设置星期，不设置时间段
- 验证预览中的错误提示（至少选择一项）

---

### 4. 上传套餐图片

**步骤：**
1. 点击"创建套餐"或编辑现有套餐
2. 在套餐图片区域：
   - **注意：只有编辑时才能上传图片** - 创建时应显示禁用状态和提示
3. 如果是编辑现有套餐：
   - 点击图片上传框（或拖拽）
   - 选择图片文件（JPG/PNG/WebP，最大5MB）
   - 上传成功后显示预览
4. 验证图片删除功能：
   - 点击图片右上角的删除按钮
   - 确认删除

**预期结果：**
- ✓ 创建套餐时上传框显示禁用
- ✓ 创建后再编辑时可以上传图片
- ✓ 图片类型验证（拒绝非JPG/PNG/WebP）
- ✓ 图片大小验证（拒绝>5MB）
- ✓ 图片预览显示正确
- ✓ 删除功能正常工作
- ✓ 后端返回正确的Cloudinary URL

---

### 5. 编辑套餐 - 验证所有字段加载

**步骤：**
1. 在套餐列表中找到之前创建的套餐（包含分组、时段、图片）
2. 点击"编辑"
3. 验证所有字段是否正确加载：
   - ✓ 基本信息（名称、描述、分类）
   - ✓ 商品列表和分组关联
   - ✓ 分组配置（应显示之前配置的分组）
   - ✓ 时段限制配置（应显示之前配置的规则）
   - ✓ 图片预览（应显示已上传的图片）
4. 修改某些字段（如分组名称、时段时间）
5. 点击"更新"

**预期结果：**
- ✓ 编辑模式正确加载所有字段
- ✓ 可以修改分组配置
- ✓ 可以修改时段限制
- ✓ 可以更新或替换图片
- ✓ 更新成功并正确保存

---

### 6. 删除套餐 - 验证级联删除

**步骤：**
1. 选择一个包含完整配置的套餐
2. 点击"删除"或操作菜单中的删除选项
3. 确认删除

**预期结果：**
- ✓ 套餐成功删除
- ✓ 套餐列表更新
- ✓ Cloudinary中的图片自动删除（如果有的话）
- ✓ 数据库中的分组和时段限制配置自动删除

---

### 7. 禁用/启用分组功能

**步骤：**
1. 编辑现有套餐（有分组配置）
2. 在商品分组配置卡片中，**取消勾选"启用商品分组"**
3. 观察分组配置界面消失
4. 点击"更新"
5. 重新编辑同一套餐
6. 验证分组配置已清除

**预期结果：**
- ✓ 取消勾选时分组界面隐藏
- ✓ 所有分组配置和商品的groupId被清除
- ✓ 商品仍然存在（不删除）
- ✓ 更新成功

---

### 8. 禁用/启用时段限制

**步骤：**
1. 编辑现有套餐（有时段限制配置）
2. 在时段限制卡片中，**取消勾选"启用时段限制"**
3. 观察时段配置界面消失
4. 点击"更新"
5. 重新编辑同一套餐
6. 验证时段限制配置已清除

**预期结果：**
- ✓ 取消勾选时配置界面隐藏
- ✓ 时段限制配置被清除
- ✓ 更新成功

---

### 9. 验证图片在套餐列表中的显示

**步骤：**
1. 返回套餐列表
2. 查看有图片的套餐
3. 验证图片是否在列表中显示

**预期结果：**
- ✓ 图片正确显示在套餐卡片中（如果有）
- ✓ 无图片的套餐显示默认占位符

---

### 10. API数据格式验证

**使用Postman或开发工具检查：**

1. **创建套餐请求：**
```json
{
  "name": "测试套餐",
  "basePrice": 999,
  "itemGroups": [
    {
      "id": "group-123",
      "name": "主食",
      "selectionType": "single",
      "minSelections": 1,
      "maxSelections": 1,
      "sortOrder": 0
    }
  ],
  "availabilityRules": {
    "enabled": true,
    "timeRange": { "start": "09:00", "end": "21:00" },
    "daysOfWeek": [1, 2, 3, 4, 5]
  }
}
```

2. **获取套餐响应：**
```json
{
  "id": "combo-123",
  "name": "测试套餐",
  "basePrice": 999,
  "imageUrl": "https://res.cloudinary.com/...",
  "itemGroups": [...],
  "availabilityRules": {...},
  "comboItems": [...]
}
```

**验证点：**
- ✓ 前端使用驼峰（imageUrl, itemGroups, availabilityRules）
- ✓ 后端使用下划线（image_url, item_groups, availability_rules）
- ✓ 数据转换正确
- ✓ 价格单位正确（后端分，前端元）

## 边界条件测试

### 1. 分组验证
- [ ] 创建分组但不分配任何商品
- [ ] 尝试创建两个同名分组（应该允许）
- [ ] 分组选择数超过商品数量
- [ ] 删除分组后商品的groupId正确清除

### 2. 时段验证
- [ ] 设置开始时间 > 结束时间（应该警告或自动调整）
- [ ] 不选择任何星期但启用"限制可用星期"（应显示错误提示）
- [ ] 只设置时间不设置星期（应该允许）
- [ ] 设置全部星期和固定时段

### 3. 图片验证
- [ ] 上传超过5MB的文件（应拒绝）
- [ ] 上传GIF、BMP等非支持格式（应拒绝）
- [ ] 上传有效的JPG/PNG/WebP
- [ ] 删除后重新上传（应正确替换）

### 4. 商品分配验证
- [ ] 同一商品不能分配到多个分组
- [ ] 删除分组后商品变为未分组
- [ ] 编辑分组不影响已分配的商品

---

## 错误场景测试

1. **网络错误**
   - [ ] 图片上传失败时显示错误提示
   - [ ] 图片删除失败时显示错误提示

2. **权限错误**
   - [ ] 验证只有有权限的用户可以编辑套餐

3. **数据格式错误**
   - [ ] 验证验证规则防止保存无效数据

## 常见问题排查

### 图片不显示
- [ ] 检查Cloudinary配置
- [ ] 检查CORS设置
- [ ] 检查网络请求（F12开发工具）

### 分组配置丢失
- [ ] 检查是否勾选了"启用商品分组"
- [ ] 检查后端数据库中item_groups字段
- [ ] 检查数据格式是否正确

### 时段限制不生效
- [ ] 检查availabilityRules.enabled是否为true
- [ ] 验证时间格式（HH:mm）
- [ ] 验证星期数值范围（0-6）
